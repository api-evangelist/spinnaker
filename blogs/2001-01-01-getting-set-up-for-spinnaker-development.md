Overview This page describes the steps a Developer should take to fetch Spinnaker’s codebase and get set up to work on it. Follow the contributing guidelines if you plan to submit your work as a patch to the open source project. System Requirements This guide assumes you have access to a machine with a minimum specification of: At least 16 GB of RAM At least 6 cores CPU MacOS These are some tools but install additional as needed the tools for your needs
